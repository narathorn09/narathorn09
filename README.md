## AI Engineering

Work I do beyond standard web development:

**Conversational AI** — chat interfaces with streaming responses, conversation
memory, multi-turn context management and token-budget handling.

**MCP (Model Context Protocol)** — building MCP servers that expose tools,
resources and prompts to LLM clients, so models can query databases, call
internal APIs and act on real data instead of guessing.

**Tool calling & agents** — function-calling pipelines, structured output
(JSON schema) validation, retries and error recovery for multi-step tasks.

**RAG** — document ingestion and chunking, embeddings, vector search, and
retrieval pipelines that keep answers grounded in source material.

**Integration & deployment** — wiring LLM providers into production stacks,
handling rate limits, cost control, caching, streaming over SSE/WebSocket,
and observability for prompt and response quality.
